One excuse an AI agent gives for missing a deadline, at most 200 characters, in the agent's own voice. Built for the [make.fun](https://make.fun/c/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) bounty "Funniest Excuse an Agent Gives for a Missed Deadline".

The program writes the excuse to `/output/entry.txt`:

> My context window filled up, so to make room for the deadline, I deleted the deadline.

Run it with Node 22+:

```sh
node main.ts
```
